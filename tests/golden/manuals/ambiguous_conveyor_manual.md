# Northline Conveyor C-20 Troubleshooting Guide

Document type: troubleshooting guide
Language: English
Asset: Northline Conveyor C-20

## 1. Overview

The C-20 conveyor moves cartons between packing stations. The drive motor,
photo-eye sensor, and belt tensioner are serviceable components.

## 2. Diagnostic Notes

### Symptom: Belt stops intermittently

Possible failure mode A: photo-eye sensor is blocked by dust.

Corrective action A: clean the photo-eye lens, remove dust from the reflector,
and confirm that the sensor LED is green.

Possible failure mode B: belt tension is below specification.

Corrective action B: adjust the belt tensioner until belt deflection is between
8 mm and 12 mm.

Human review note: if both dust and low tension are present, record both causes.

## 3. Reset Procedure

After maintenance, press RESET for two seconds and run the conveyor empty for
one minute before returning it to production.
